claude-gdrive

A personal tool for publishing files to my own Google Drive

claude-gdrive is a small command-line tool that runs on the owner's own computer. It does three things with the owner's Google account:

  1. uploads a local file (usually a presentation PDF) to a folder in the owner's Google Drive, or replaces the content of a file it uploaded earlier so the share link stays the same;
  2. sets that file to “anyone with the link can view” (never edit);
  3. writes the link into a cell of a Google Sheet the owner chooses.

It is not a hosted service. There is no server, and no one else's account is used.
