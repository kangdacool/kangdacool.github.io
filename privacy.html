Privacy policy

claude-gdrive · last updated 2 October 2026

Who uses it

claude-gdrive is a personal tool used only by its owner, with the owner's own Google account, on the owner's own computer.

What it can access

  • Google Drive (drive.file): only files and folders that this tool itself created. It cannot see or change any other file in the Drive.
  • Google Sheets (spreadsheets): used only to write a link into a cell the owner chooses.

What it does with the data

  • Files are uploaded from the owner's computer to the owner's Drive and nowhere else.
  • Uploaded files are shared as “anyone with the link can view”. The tool never grants edit access.
  • The sign-in token is stored only on the owner's computer, outside any synced folder.
  • No data is sent to the maintainer or to any third party, and nothing is sold, logged remotely or used for advertising.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Files the tool uploaded stay in the owner's Drive until the owner deletes them.
